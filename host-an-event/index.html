Built to make life easier for fishing clubs

Spend less time chasing entries and paperwork, with tools for tournament directors, catch approvers and anglers.

01

Hosted event setup & entry

We set up your approved tournament so eligible anglers can find it, review the rules and join in the app.

02

Catch submissions

Anglers can submit catch photos, species and measurements through the app instead of chasing paper records.

03

Catch review & scoring

Event administrators can review submitted catches and manage results against the event's rules.

04

Live leaderboards

Keep competitors and followers engaged with a live view of tournament standings and results.

05

Teams & tournament controls

We create the tournament; nominated directors and approvers then use their assigned tools to help run it.

06

Offline catch saving

Anglers who load their event details before leaving reception can save catches offline for upload when connectivity returns.

What kind of event are you planning?

Whether it's a one-day competition or a longer fishing challenge, we'd love to hear about it.

  • Fishing club competitions
  • Social fishing events
  • Kayak and boat tournaments
  • Species-specific challenges
  • Charity and fundraising events
  • Monthly fishing competitions

Event formats and features are discussed with organisers before hosting is confirmed.

How to request your event

All tournaments are created by Lure Therapy Tournaments after a club or organiser requests hosting.

1

Request an event

Send us your event name, dates, location, target species, format and expected number of anglers.

2

Confirm the details

We'll talk through your event requirements, hosting options, any fees and how entries and scoring could work.

3

We set up the event

Once arrangements are agreed, we create the event and set up its tournament details. Anglers can then join through the app.
